## Direction contract

THESIS: The site gives Denise's grabados the same disciplined confidence a Swiss poster series gives a concert run — one modular grid, never decorative chrome — while borrowing printmaking's own technical marks (registration crosses, crop marks, edition/plate numbering) as the UI's typographic and structural language, refusing the generic "artist template" (soft serif hero, arbitrary Pinterest masonry, decorative flourish).

OWN-WORLD: Cool unprinted-paper white ground (not cream/ivory), ink-black for type and rules, one restrained proof-mark red (~#C22A1F) reserved for active/hover state only — never decorative. Display type: an objective grotesque (Archivo) set flush-left, ragged-right, sized in stepped grid units. Technical/numeric labels (kicker, edition numbers, hover marks): a mono face (JetBrains Mono), tracked and small. A strict modular grid (12-col base) places gallery pieces in varying spans for real asymmetric rhythm — not randomized masonry. Thin hairline rules echo registration bars; no shadows, no gradients, no rounded "card" chrome.

STORY: Visitor lands on a quiet, confident threshold (name + "Portfolio de Arte" as a technical kicker), scrolls into a disciplined sequence of grabados held by the grid, hovers a piece to see a registration-cross mark strike in and a precise scale/brightness settle, and closes on a spare colophon-style footer carrying only the Instagram link — no case studies, no invented bio, no sales language.

FIRST VIEWPORT: Full-height hero. Large flush-left wordmark "Denise Lo Guercio" in Archivo, a small mono kicker "PORTFOLIO DE ARTE — GRABADOS" above or beside it, a thin baseline rule anchoring the lower third like a registration bar. No imagery in the hero itself — the hero is a quiet threshold before the work, generous whitespace on all sides. Entrance: grid modules/text resolve in with a short staggered fade+rise (Motion library), never bouncy.

FORM: Won direction — challenger `design-canon-swiss-grid-poster-wall` (Swiss International Style concert-poster wall), fused against assigned candidate 7 (letterpress specimen sheet) from my own grounded list; won both axes (audience identification, product clarity). User confirmed via structured question round. Seed key 58358d95.

SIGNATURE INTERACTION: Registration-cross hover mark (a small red + mark strikes in at the piece's corner) paired with a precise, fast scale/brightness settle (~180ms, custom easing) on gallery images — translates the brief's requested "hover zoom/brightness" into the world's own vocabulary instead of a generic card-hover.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
